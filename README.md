Campus Recruitment System

Hi, I am Nandhini and I built this project using PHP, MySQL and Bootstrap.
This is a web application where students can register, browse job openings and apply for them. They can also track whether they got shortlisted or selected by the company.
I also built an admin panel where the admin can post new jobs, view all student applications and update the status like shortlisted, selected or rejected.
Technologies I used:

PHP
MySQL
Bootstrap
XAMPP

Steps to run the project:

Install XAMPP
Copy the project folder to htdocs

Import database.sql in phpMyAdmin

Open browser and go to http://localhost/project/index.php
